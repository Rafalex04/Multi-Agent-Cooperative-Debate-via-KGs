BreastMNIST KG-Debate Ledger

Every configuration measured in this project, recomputed from the raw result files rather than quoted from notes. Each row carries a plain-language description of what it actually is. Balanced accuracy sits alongside AUC throughout, and partial runs are flagged as partial.

00How to read every table

AUC
Ranking quality: the chance a random malignant image is scored higher than a random benign one. 0.5 is coin-flip, 1.0 is perfect. It ignores where you set the decision threshold. Ties are handled correctly ((a>b) + 0.5·(a==b)) — an earlier uncorrected version understated one method by 0.18.
bAcc — balanced accuracy
Average of sensitivity and specificity at one fixed decision threshold. This is the number that matters clinically. The split is 42 malignant / 114 benign, so plain accuracy is misleading — always predicting "benign" scores 73% accuracy and 0.50 bAcc.
bAcc* — oracle
Balanced accuracy with the threshold swept on the test set to find the best one. It is an upper bound, not an achievable result. It is shown only where no honest threshold was available, and never used in the standings.
train / val / test
The official BreastMNIST splits: 546 / 78 / 156 images, never re-split. Where a table shows all three, the point is consistency — a number that appears on test but not on the 546-image train split is noise, and that pattern caught four false positives in this project.
±
Standard deviation across 5 random seeds. A difference smaller than the ± is not a difference.
mal_share
The fraction of claims in a debate that concluded MALIGNANT. A pure count with no model on top — this is the debate's own verdict, used directly as a prediction score.

The governing finding

Putting a list of findings in the prompt saturates the output. Free text produced 100% ties; retrieval v2 produced 42.6%. The KG helps only when it decides what single question to ask and how to weight the answer — never when it is text the model reads before deciding.

The control is not degenerate — it argues just as much (18.9 vs 19.5 claims), links more KG triples, and has higher claim diversity. Its conclusions simply do not track the image. This is the cleanest evidence that the knowledge graph is what makes the debate informative.

The learned weights, and why they matter

stance=MAL   AGREE +0.660   DISAGREE −0.042   OPEN +0.215
stance=BEN   AGREE −0.676   DISAGREE −0.008   OPEN −0.374

claim-level precision, v5q:
  verdict AGREE     P(mal|MAL) 0.408   P(ben|BEN) 0.836   lift +0.176
  verdict DISAGREE  P(mal|MAL) 0.263   P(ben|BEN) 0.735   lift −0.070
  KG-free control:  AGREE lift only +0.066

Rebuttal claims carry essentially zero evidence — both DISAGREE weights sit at ~0.00. Only opening claims and genuine agreements predict the image, so two of the three debate rounds are noise for classification. Since the graph holds 10.4 DISAGREE edges against 1.5 AGREE per graph, its topology is built almost entirely from the uninformative relation — which explains the GNN result completely.
